# Touch Controls

!!! warning "Draft for 1.21"
    Being written alongside the 1.21 release; *TODO* sections are filled in from the finished feature.

On a phone or tablet, games show **on-screen controls**: a stick to move and **action buttons** — jump, shoot,
interact — for the game's own actions.

## When they show

**Settings ▸ *TODO* ▸ Touch controls**: **Auto** (the default — shown on touch screens, where the main pointer is a
finger), **On** or **Off**.

## The buttons

The buttons come from the game's **input actions** (see [Build a Game Loop](build-a-game.md)): a game that has a *Jump*
and an *Interact* action gets a Jump and an Interact button, with no extra setup. *TODO (36-touch): default layout,
labels/icons, multi-touch behaviour.*

# Sharing into the App

*New in 1.44.* Once theprototype is **installed** (your browser's *Install app*, or *Add to Home screen* on a
phone), files can come into it from the rest of your device.

## Share from your phone

On Android, **Share** a file from the gallery, the file manager or another app and pick **theprototype**:

| You share | What happens |
|---|---|
| a picture | it goes into your **Explorer Library**; the toast offers **Show in Library** (drag it onto an object to texture it) and **Use as reference** (a [reference image](reference-images.md) on the ground) |
| a `.glb` / `.gltf` model | it is placed in the scene you have open |
| a `.tpscene` | it opens as the current scene |

Desktop Chrome's share menu works the same way.

## Open files from your desktop

With the app installed, a `.tpscene`, `.glb` or `.gltf` opens in it: right-click the file ▸ **Open with** ▸
**theprototype**, or double-click once your system links the type to the app. A scene opens; a model is added to the
scene you have open. A second file goes to the window that is already open instead of starting another one.

## Good to know

- It needs the **installed** app — a browser tab cannot be picked in the share sheet.
- If the app is asking **Restore previous session?**, the shared file waits until you answer.
- A file of another kind is skipped with a note saying which types the app takes.
- Some Android apps share a model as a generic file; if one is skipped, save it and open it from the Explorer instead.
